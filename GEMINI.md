# Agentic QA Sandbox: GEMINI.md

## Protocols

### 1. Crawl-Walk-Run
- **Crawl:** Establish the foundational environment. Minimal configurations, "Hello World" implementations, and basic connectivity checks. No complex abstractions.
- **Walk:** Integrate core components. Implement basic page objects, initial Next.js routes, and simple end-to-end test cases. Focus on stability and architectural alignment.
- **Run:** Full-scale automation and feature development. Agentic workflows, comprehensive test suites, CI/CD integration, and performance optimizations.

### 2. Code Deconstruction
- **Identify:** Before modification, identify all affected components and their dependencies.
- **Map:** Trace data flow and control paths to understand side effects.
- **Analyze:** Evaluate existing patterns (naming, structure, typing) to ensure new code is idiomatic and consistent.
- **Execute:** Apply surgical changes based on the gathered insights.

## Project Vision
To build a robust sandbox for agentic QA experimentation, leveraging Next.js for the UI/Control plane and Playwright for the automation engine.
